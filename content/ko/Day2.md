# 첫 번째 Streamlit 앱 만들기

## IDE 실행하기

Atom, VS Code 또는 GitPod나 GitHub.dev 같은 클라우드 IDE 등 사용하려는 IDE를 실행합니다.

`streamlit_app.py`라는 파일을 만듭니다.

## 첫 코드 입력하기

새로 만든 파일에 다음 코드를 입력합니다.

```
import streamlit as st

st.write('Hello world!')
```

파일을 저장합니다.

## 명령줄 터미널 실행하기

터미널에 다음을 입력합니다.

```
streamlit run streamlit_app.py
```

새로 만든 Streamlit 앱이 표시된 브라우저 창이 열립니다.

**축하합니다!** 첫 번째 Streamlit 앱을 만들었습니다!
