# Streamlit Community Cloud로 Streamlit 앱 배포하기

이번 챌린지는 만든 앱을 다른 사람과 공유하고 싶은 분을 위한 선택 과정입니다. 배포하지 않아도 같은 실습 폴더에서 다음 Streamlit 챌린지를 계속할 수 있습니다.

## Streamlit Community Cloud

[Streamlit Community Cloud](https://streamlit.io/cloud)는 Streamlit 앱을 손쉽게 배포할 수 있는 호스팅 서비스입니다.

## Streamlit Community Cloud 가입하기

Google 또는 GitHub 계정으로 로그인하기만 하면 [Streamlit Community Cloud](https://streamlit.io/cloud)에 간편하게 가입할 수 있습니다.

## Streamlit 앱 배포하기

Streamlit 앱을 배포하려면 다음 단계를 따릅니다.
1. GitHub 또는 Gmail 계정 정보로 로그인합니다.
2. 앱 코드와 필요한 `requirements.txt`를 올린 저장소, 브랜치, 시작 파일(`app.py`)을 선택합니다. 파일 준비는 [Community Cloud 배포 안내](https://docs.streamlit.io/deploy/streamlit-community-cloud/deploy-your-app)를 참고하세요.
3. Deploy를 클릭합니다.

배포한 앱은 GitHub 저장소의 변경 사항을 반영합니다. 로컬 실습은 지금까지처럼 `app.py`를 수정하고 저장하면 됩니다.
