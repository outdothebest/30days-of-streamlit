# Streamlit Community Cloud로 Streamlit 앱 배포하기

## Streamlit Community Cloud

[Streamlit Community Cloud](https://streamlit.io/cloud)는 Streamlit 앱을 손쉽게 배포할 수 있는 호스팅 서비스입니다.

## Streamlit Community Cloud 가입하기

Google 또는 GitHub 계정으로 로그인하기만 하면 [Streamlit Community Cloud](https://streamlit.io/cloud)에 간편하게 가입할 수 있습니다.

## Streamlit 앱 배포하기

Streamlit 앱을 배포하려면 다음 단계를 따릅니다.
1. GitHub 또는 Gmail 계정 정보로 로그인합니다.
2. 저장소, 브랜치, 파일을 선택합니다.
3. Deploy를 클릭합니다.

그런 다음부터는 git push를 할 때마다 앱이 즉시 업데이트됩니다.
