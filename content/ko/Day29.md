# Hugging Face와 Streamlit으로 제로샷 학습 텍스트 분류기 만들기

오늘의 챌린지에서는 [Charly Wargnier](https://twitter.com/DataChaz)가 Hugging Face와 Streamlit으로 제로샷 학습 텍스트 분류기를 개발하는 과정을 안내합니다.

## 소개

Streamlit을 사랑하는 여러분, 안녕하세요!

오늘 이 실습 튜토리얼로 30DaysofStreamlit 챌린지에 기여할 수 있게 되어 기쁩니다! 🎈

## 무엇을 만들까요?

Hugging Face의 API 추론과 Distilbart를 사용해 제로샷 학습 텍스트 분류기를 만들겠습니다!

사전에 머신러닝 모델을 학습시키지 않고도 핵심 구절을 즉석에서 빠르게 분류할 수 있습니다!

분류 레이블을 만들고 핵심 구절을 붙여 넣으면 준비 끝입니다!

레이블은 다음과 같이 원하는 대로 지정할 수 있습니다.

- 감성 분석을 위한 긍정, 부정, 중립
- 감정 분석을 위한 화남, 행복, 감정적
- 의도 분류를 위한 탐색형, 거래형, 정보형
- 취급하는 제품군(가방, 신발, 부츠 등)

직접 정해 보세요!

기대되시나요? 그럼 시작해 봅시다!
